# PDQ fingerprint

Pure TypeScript port of Meta ThreatExchange PDQ at revision c91e539d0654fae57e553160c15060dfa10cddb8 (BSD-3-Clause; retained LICENSE-Meta.txt). Reference: https://github.com/facebook/ThreatExchange/tree/c91e539d0654fae57e553160c15060dfa10cddb8/pdq/cpp .

Uses float32 RGB luma, two Jarosz XY passes, center decimation to 64x64, DCT frequencies (1..16)x(1..16), lower median, and upstream quality quantization. Bit i corresponds to upstream setBit(i); hex prints most significant word first. Alpha is ignored, matching RGB reference behavior; composite transparent input before hashing. Tiny inputs below 5 pixels reject.

API: pdqHash(imageData), hamming(hex64, hex64), MATCH_THRESHOLD=31, re-exported sha256Hex. The synchronous API is worker-safe. fingerprint.worker.ts accepts {id,image} and replies {id,value:{hash,quality}}; instantiate it with new Worker(new URL('./fingerprint.worker.ts', import.meta.url), {type:'module'}) to avoid blocking the UI. Terminate the worker to cancel.

No published fixture assets are vendored. Four synthetic vectors in tests were independently generated by compiling the actual pinned upstream C++ implementation (g++ -O2 -ffp-contract=off), with xorshift32 seed 123456789 and square dimensions 64,128,257,512. All 256 bits and quality values match. Tests additionally use a generated photo-like texture through actual JPEG75+0.8 resize. Threshold is a similarity heuristic, not proof of derivation; crops and large edits can change PDQ substantially. Low quality reduces usefulness.
